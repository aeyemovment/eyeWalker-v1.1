# License summary

eyeWalker uses path-scoped licensing. Read LICENSE, LICENSE-MIT, and
DUAL_LICENSE.md before reuse; this page is a plain-language summary, not legal
advice.

- PolyForm Noncommercial 1.0.0 is the fail-closed default for every path.
- Only the exact individual mobile and static-PWA files enumerated in
  `DUAL_LICENSE.md` use MIT. New files, including new files under `mobile/`,
  default to PolyForm unless explicitly added to that allowlist.
- The NeuroAgent AI logo is outside that MIT allowlist, and neither license
  grants trademark rights.
- PolyForm Noncommercial is source-available but is not an OSI-approved
  open-source license.
- Commercial rights cannot be inferred from public source availability.

For questions about separate commercial permission, use the repository issue
tracker. Do not infer the license for a new or renamed file from its directory;
read the exact allowlist. Do not rely on this summary if the canonical license
text is unclear.
