# eyeWalker deterministic synthetic fixtures — schema v1.1.0

**Software version 1.1.9. Synthetic pipeline/interface regression data only.**

This directory contains 26 programmatically generated abstract PNG fixtures
and 312 deterministic JSON records. No captured walk video, camera photo,
bystander, face, plate, precise location, image-model output, or validated
ground truth belongs in this public corpus.

## Contract

| Field | Value |
|-------|-------|
| Source | 26 canonical abstract PNG fixtures generated by repository code |
| Records | 312: 26 fixtures × 4 visual conditions × 3 twins |
| Purpose | Generator, provenance, interface, and CI regression testing |
| Model execution | None |
| Navigation/clinical use | Prohibited |

Every cue begins SIMULATED RESEARCH CUE: and ends Keep your cane or guide dog.
Not a medical device. Obstacles and measurements are synthetic test records,
not detections.

## Layout

- frames/ — generated source fixtures with visible simulation watermark.
- synthetic/ — one-to-one JSON labels, aggregate JSONL, and manifest.
- exports/v1_1_synthetic_manifest.json — identical manifest export.

## Reproduce

Run:

    python3 scripts/v11/rebuild_synthetic_frames.py
    python3 scripts/v11/rebuild_synthetic_dataset.py

Both commands must be deterministic. CI reruns them and requires a clean diff.

## Personal media

Do not copy personal walk media into this repository. The optional
train_from_video helper requires an explicit source and an external output
directory; it performs frame extraction only and makes no model, label,
ground-truth, or safety claim.

## Safety

SIMULATED RESEARCH ONLY. Do not use these records for mobility or navigation.
Keep your cane or guide dog. Not a medical device.
